Security First

Built for privacy & security

Every layer hardened — from API key isolation to XSS prevention. Your investigation data never leaves your server.

  • 🔑
    API Keys Never Leave the Server
    All OSINT API keys are loaded server-side from .env — never sent to the browser or logged.
  • 🍪
    httpOnly JWT Cookies
    Auth tokens stored in httpOnly, SameSite=Strict cookies — immune to XSS token theft.
  • ⚡
    Rate Limiting + Account Lockout
    5 auth attempts/min, 10 scans/hour per user, 15-minute lockout after 5 failed logins.
  • 🛡️
    Injection & XSS Protection
    Strict regex validation, SQLAlchemy ORM, CSP headers, and XSS-safe DOM rendering.
